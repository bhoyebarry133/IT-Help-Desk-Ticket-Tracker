
# IT Help Desk Ticket Tracker

## Project Overview

The IT Help Desk Ticket Tracker is a Python-based code that allows users to create, view, and update IT support tickets. The program organizes support requests by issue, description, priority, and status.

Tickets are saved in a JSON file so that information remains available even after the program is closed.

## Features

- Create IT support tickets
- Assign a unique ticket ID
- Add issue descriptions
- Set ticket priority
- View all tickets
- Update ticket status
- Save tickets to a JSON file
- Load saved tickets when the program starts

## Methods  Used

- Python
- JSON
- Dictionaries
- Lists
- Functions
- Loops
- Conditional Statements

## Ticket Priorities

- Low
- Medium
- High

## Ticket Statuses

- Open
- In Progress
- Closed
