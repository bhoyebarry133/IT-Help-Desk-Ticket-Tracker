
# IT Help Desk Ticket Tracker

## Project Overview

The IT Help Desk Ticket Tracker is a Python-based application that allows users to create, view, and update IT support tickets. The program organizes support requests by issue, description, priority, and status.

Tickets are saved in a JSON file so that information remains available after the program is closed.

## Features

- Create IT support tickets
- Assign a unique ticket ID
- Add issue descriptions
- Set ticket priority
- View all tickets
- Update ticket status
- Save tickets to a JSON file
- Load saved tickets when the program starts
- Validate ticket IDs and menu selections

## How to Run

1. Install Python.
2. Open the project in PyCharm.
3. Run the Python program.
4. Select an option from the help desk menu.
5. Create, view, or update tickets.
